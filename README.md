# Grateful
Next.js (App Router) + Supabase. Run locally: `npm install` then `npm run dev`.
Deploy on Vercel: import the repo, add env vars NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY (see .env.local.example), deploy.
Never put the Supabase secret / service_role key in this project.
